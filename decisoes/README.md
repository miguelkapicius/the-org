# Registro de decisões

Cada decisão importante vira um arquivo `NNNN-titulo-curto.md` (copie `0000-modelo.md`).

**Quando registrar:** a escolha afeta mais de uma seção, é difícil de desfazer, ou já foi debatida (para não debater de novo).

**Status:**
- `proposta` — em discussão no PR
- `aceita` — vale como contrato
- `rejeitada` — fica registrada para não ser proposta de novo
- `substituida-por-NNNN` — trocada por uma decisão mais nova

Decisões aceitas **não são editadas**. Para mudar, crie uma nova que substitua a antiga.
