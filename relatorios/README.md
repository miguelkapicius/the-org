# Relatórios

Análises pontuais (diagnósticos, medições, comparações) para os agentes e os autores lerem e decidirem. Um arquivo por relatório, com a data no nome: `AAAA-MM-DD-assunto.md`.

- Um relatório **não é decisão nem GDD**: registra o que foi visto, medido e proposto naquele momento. O que for decidido vai para `decisoes/`; a lista de trabalho viva fica na seção do GDD que o relatório indicar.
- Cada número diz de onde saiu (comando, quantas partidas) e cada conclusão diz a confiança.
